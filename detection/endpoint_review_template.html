Review existing spur annotations

These are draft visual labels, not verified measurements. Correct the visible outline, mark the attachment base and distal tip, or leave an endpoint unresolved. Previews use the existing 600 × 600 coordinate reference. Original images and age labels stay unchanged. Nothing is uploaded.

Save it as detection/endpoint_reviews.reviewed.json. The downloaded file does not overwrite originals or activate a model.

Export the reviewed training set with python detection/export_measurement_annotations.py --labels detection/endpoint_reviews.reviewed.json --output detection/derived/measurement_reviewed_v2. Only approved images are eligible, and every split must remain represented.
